# Docker Engine Installation

## Overview
Docker Engine and Docker Compose were installed on the Ubuntu Server VM to support containerised security services.

## Installation Method
The official Docker repository was used to ensure compatibility and up-to-date packages.

## Validation
- Docker service enabled and running
- Non-root Docker usage configured
- hello-world container executed successfully

## Outcome
The environment is now capable of running multiple lightweight security services using Docker Compose.
